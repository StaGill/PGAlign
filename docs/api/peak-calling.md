# PeakCalling

The `PeakCalling` class implements GALAXY's Steps 1 (Peak Calling) and 2
(Peak Grouping). Two variants are available:

- [`PeakCalling`](#GalaxyPython.PeakCalling.PeakCalling) &mdash; two-spectrum joint peak calling and grouping.
- [`PeakCalling_single`](#GalaxyPython.PeakCalling.PeakCalling_single) &mdash; single-spectrum variant.
- [`PeakCallingmv`](#GalaxyPython.PeakCalling.PeakCallingmv) &mdash; moving-average pre-smoothed variant.
