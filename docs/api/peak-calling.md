# PeakCalling

The `PeakCalling` class implements PGAlign's Steps 1 (Peak Calling) and 2
(Peak Grouping). Two variants are available:

- [`PeakCalling`](#pgalign.PeakCalling.PeakCalling) &mdash; two-spectrum joint peak calling and grouping.
- [`PeakCalling_single`](#pgalign.PeakCalling.PeakCalling_single) &mdash; single-spectrum variant.
- [`PeakCallingmv`](#pgalign.PeakCalling.PeakCallingmv) &mdash; moving-average pre-smoothed variant.
