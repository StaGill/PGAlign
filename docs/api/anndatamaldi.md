# AnnDataMALDI

The `AnnDataMALDI` class implements GALAXY's Steps 3 (Peak Group Pairing) and
4 (Fine Alignment Assessment). Helper classes for simulation
(`MALDI_SIM`, `PGmzalign`) are also exposed here.
