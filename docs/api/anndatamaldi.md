# AnnDataMALDI

The `AnnDataMALDI` class implements PGAlign's Steps 3 (Peak Group Pairing) and
4 (Fine Alignment Assessment). `PGmzalign` produces the aligned dataset after
Step 4, and `MALDI_SIM` generates the shifted, noisy spectra of the simulation
study.
