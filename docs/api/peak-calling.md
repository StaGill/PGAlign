# PeakCalling

The `PeakCalling` class implements PGAlign's Steps 1 (Peak Calling) and 2
(Peak Grouping). Two variants are available:

- [`PeakCalling`](#pgalign.PeakCalling.PeakCalling): two-spectrum joint peak calling and grouping.
- [`PeakCalling_single`](#pgalign.PeakCalling.PeakCalling_single): single-spectrum variant.
- [`PeakCallingmv`](#pgalign.PeakCalling.PeakCallingmv): moving-average pre-smoothed variant.
